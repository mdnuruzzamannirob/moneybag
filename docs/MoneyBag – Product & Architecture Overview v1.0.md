## 1. Executive Summary

MoneyBag is a subscription‑based personal and family finance management platform. It serves individuals who track income, expenses, budgets, and savings across multiple wallets (bank, cash, mobile banking, etc.). Pro users unlock family collaboration features – shared wallets, expense splitting, pooled budgets – and an integrated administration panel lets operators manage the platform, users, and billing.

This document provides a high‑level overview of the product’s features, target users, subscription model, system architecture, and security posture. Detailed technical specifications are covered in separate Backend, Frontend, and Operations documents.

## 3. Locked Feature Set (MVP)

All features listed below are committed for the initial release. No changes will be made without formal review.

### 3.1 Personal Finance (Free & Pro)

**Authentication & Security**

- Email/password registration with automatic 14‑day Pro trial (no credit card required)
- Google OAuth 2.0 login
- Password reset via secure email link
- JWT‑based sessions: access token (15 min) + single‑use refresh token (rotation with replay detection)
- CSRF protection on all state‑changing endpoints (except auth and Stripe webhook)
- Rate limiting: 200 req/15 min general, 20 req/15 min auth

**User Profile & Settings**

- View own profile: name, email, avatar URL, currency, theme, role, trial status, preferences
- Edit name, avatar URL, currency, theme (light/dark/system)
- Change password (current password required)
- **Notification preferences:** toggle email budget alerts, recurring reminders, marketing emails
- GDPR‑compliant data export (JSON) and permanent account deletion (cascades through owned family groups)

**Wallets**

- Create and manage multiple financial accounts: Bank, Cash, Mobile Banking, Credit/Debit Card, Investment
- Each wallet holds a currency‑specific balance
- Update wallet name, icon, color, default flag
- Internal wallet‑to‑wallet transfer with auto‑generated transaction records
- **Free plan:** max 1 wallet; **Pro:** unlimited

**Categories**

- Personal income/expense categories with name, icon, color
- Full CRUD; deletion blocked if referenced by transactions or budgets

**Transactions**

- Create, edit, delete income/expense transactions
- Fields: wallet, category, amount (Decimal), type, date, note, tags, recurring rule
- Advanced filtering: wallet, type, category, date range, tags, search (notes + tags)
- Sorting by date, amount, creation time; pagination
- **Recurring transactions:** daily/weekly/monthly (auto‑generated by daily cron job)
- **CSV bulk import (Pro only):** 1 MB file, validated, atomic – all rows succeed or entire import rolls back
- **Delete transaction reverses wallet balance** (expense → amount added back; income → subtracted)
- **Transaction tags autocomplete** endpoint for UI
- **Free plan:** 50 transactions per calendar month (UTC); **Pro:** unlimited

**Budgets**

- Monthly/Yearly expense budgets linked to a category or overall
- Configurable alert threshold (default 80%); email notification when crossed
- **Rollover:** unspent amount automatically carried to next period
- API response includes `effectiveLimit` (limit + rolled‑over amount)
- **Free plan:** max 2 budgets; **Pro:** unlimited

**Savings Goals**

- Create goal with title, target amount, deadline
- Log contributions (amount, date, note) – increments current amount
- **Withdraw from goal** (amount ≤ currentAmount) – decreases current amount
- Progress percentage (capped at 100%)
- **Free plan:** max 1 goal; **Pro:** unlimited

**Reports & Export**

- Monthly summary (total income, total expense, net savings)
- Yearly summary
- Category breakdown (expenses grouped by category for a given month)
- Daily trend (income & expense per day over a date range)
- Export monthly summary as PDF or CSV
- Report data cached in Redis for 5 minutes; invalidated on any transaction mutation

**Subscription & Billing**

- Plans: Free, Pro Monthly ($4.99/mo), Pro Yearly ($49.99/yr), Unlimited Lifetime ($99.99 once)
- 14‑day free trial of Pro Monthly automatically activated on registration
- Stripe Checkout for paid plans; Stripe Customer Portal for billing history
- **Coupon codes:** percentage or flat‑amount discount, redeemable at checkout
- **Trial ending reminder:** email sent 3 days before trial expiry
- **Downgrade policy:** when moving to a lower plan, existing data is retained but new creations are blocked until usage falls within new limits; family groups become inactive (owner must delete or upgrade)

### 3.2 Family Finance (Pro only)

**Group Management**

- Create a family group (max 1 per Pro user)
- **Update group name** (owner only)
- **Delete group** (owner only, with email notification to all members)
- List own groups (as owner or member)

**Members**

- Invite up to 5 members by email
- Remove member (owner only)
- **Self‑leave group** – any member can leave except the owner (owner must transfer ownership or delete group)
- Change member role: Viewer (read‑only) or Editor (can add/edit transactions and settlements)

**Shared Wallets**

- Owner creates shared wallets (e.g., “Family Groceries”)
- All editors can log transactions; balances visible to all members

**Transaction Splitting & Settlement**

- Family transactions in shared wallets record `paidBy` (who paid) and split details
- Split types: Equal, Percentage, Exact (with per‑member amounts)
- Automatic net balance calculation: who owes whom within the group
- **Settlement:** any editor can record a payment between members to clear debts
- Validation: split sums must equal transaction amount; settlement amount ≤ net balance

**Pooled Budgets**

- Owner creates family budgets tied to a shared wallet and optionally a category
- All editors’ transactions in that wallet contribute to budget consumption
- Alerts emailed to all members when threshold crossed
- Rollover works at group level

**Family Categories**

- Default categories created on group creation (Groceries, Utilities, Rent, etc.)
- Owner can add, edit, or delete family categories

**Aggregated Reports**

- Family dashboard: total income/expense across all shared wallets, category breakdown, per‑member contribution summary
- Owner can export family reports as PDF/CSV

### 3.3 Administration Panel (ADMIN role only)

**Dashboard**

- KPIs: total users, active trials, MRR, churn rate, active users today, plan distribution
- Charts: new registrations over time, plan distribution pie chart

**User Management**

- List/search users by email, name, role, status, plan; pagination
- View detailed user profile (wallets, subscription, recent activity)
- Activate/deactivate accounts
- **Impersonate** any user (temporary JWT, 10‑minute expiry, single‑use)
- Manually assign a plan to any user

**Subscription & Plan Management**

- View all subscriptions with filters; issue refunds (Stripe); cancel or reactivate
- CRUD for plans (name, slug, price, interval, limits JSON, active flag)

**Coupon Management**

- CRUD for coupons (code, discount type/amount, expiry, max redemptions, active)

**Family Group Management**

- List and search all family groups (by name, owner email)
- View group details (members, wallets, budgets) – read‑only
- Delete or deactivate any group (abuse prevention)

**Email Templates**

- Edit HTML templates for: welcome, password reset, budget alert, subscription expiry, trial ending, group deletion

**Audit Logs**

- Immutable log of all admin actions and sensitive user events (login, password change, plan change, impersonation)

**Global Settings**

- Configure SMTP, Google OAuth credentials, storage keys (Cloudinary/S3), maintenance mode toggle, legal page content (Terms, Privacy)

### 3.4 Notifications & Automation

- Welcome email on registration
- Password reset email (one‑time token, expires 1 hour)
- Budget threshold alert emails (personal and family)
- Trial ending reminder email (3 days before expiration)
- Family group deletion email to all members
- Automated recurring transaction generation (cron job)
- Budget alert checker (cron job)
- Graceful email handling: if SMTP is not configured, emails are logged; if delivery fails, a warning is logged

### 5.3 Authentication Flow

1. User logs in/registers → backend validates credentials, hashes password (bcrypt), issues access (15 min) and refresh (7 day) tokens.
2. Tokens delivered as HttpOnly, Secure, SameSite=Lax cookies. Access token also accepted via `Authorization: Bearer` header.
3. Frontend automatically attaches CSRF token (`X-XSRF-TOKEN` header) on state‑changing requests, read from non‑HttpOnly cookie.
4. On token refresh, the used refresh token is immediately revoked; a new pair is issued. Any reuse of a revoked token revokes all tokens for that user (replay protection).
5. Admin routes are protected by RBAC middleware; family routes verify group membership and role (viewer/editor).

### 5.4 Background Jobs (Cron)

- **Recurring Transaction Generator** (daily at 00:05 UTC): Creates non‑recurring copies of transactions where `isRecurring = true` and the rule matches the current date.
- **Budget Alert Scheduler** (daily at 08:00 UTC): For every budget in the current month, if spending >= threshold%, sends email alert.
- **Trial Ending Reminder** (daily at 10:00 UTC): Checks for trials ending in 3 days and sends a reminder email.
- In production, only one instance runs cron jobs (controlled by `ENABLE_CRON=true` environment variable).

### 5.5 Deployment Model

- **Frontend:** Deployed on Vercel; environment variables set in dashboard.
- **Backend:** Docker image built via multi‑stage build; deployed on AWS ECS Fargate or Railway. Multiple instances behind a load balancer; cron worker designated via environment.
- **Database:** Managed PostgreSQL (e.g., Supabase, RDS). Migrations run manually or via CI step.
- **Redis:** Managed instance (e.g., Upstash, ElastiCache) for caching and rate limiting.
- **CI/CD:** GitHub Actions runs lint, type‑check, tests, builds Docker image, and deploys on push to main.

## 6. Security & Compliance Highlights

- All traffic HTTPS; Helmet headers enforced.
- Rate limiting (global and auth) protects against brute‑force attacks.
- CSRF tokens on all mutations (except auth and Stripe webhook).
- Passwords hashed with bcrypt (12 rounds); never logged.
- Monetary amounts stored as `Decimal(12,2)` to avoid floating‑point errors.
- GDPR‑compliant data export and permanent account deletion (with cascading removal of owned family groups).
- Stripe handles PCI‑DSS compliance; webhook endpoint exempt from CSRF and rate limiting.
- Audit logs record all admin actions and sensitive user events.
- Sensitive data (tokens, passwords, emails) are never logged.
